# Codex Guidance

- Make small, focused edits that directly support the requested change.
- Keep Apptrack refined, minimal, accessible, and mobile-friendly.
- Preserve the job application workspace, resume manager, deadline, and follow-up direction.
- Prefer the existing typed domain model, client-side persistence, and editorial visual system.
- Avoid unnecessary dependencies and backend services.
- Do not commit secrets, API keys, `.env` files, build output, or dependency folders.
- Test locally after meaningful changes, especially application CRUD and import flows.
- Explain which files changed and why after edits.
