# Codex Guidance

- Make small, focused edits that directly support the requested change.
- Keep the health journal refined, minimal, accessible, and mobile-friendly.
- Preserve calorie tracking, food logging, hydration, trends, and weight direction.
- Prefer the existing REST API, SQLite persistence, and editorial visual system.
- Avoid unnecessary dependencies and backend services.
- Do not commit secrets, API keys, `.env` files, build output, or dependency folders.
- Test locally after meaningful changes, especially food entry CRUD and settings flows.
- Explain which files changed and why after edits.
