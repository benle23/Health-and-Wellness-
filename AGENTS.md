# Codex Guidance

- Make small, focused edits that directly support the requested change.
- Do not rewrite unrelated files or redesign the app without an explicit request.
- Keep LoopLog minimalistic, premium, golf-focused, and mobile-friendly.
- Preserve the golf journal plus Strava-style activity feed direction.
- Prefer existing app structure, components, Tailwind styling, and mock data patterns.
- Avoid unnecessary dependencies.
- Do not commit secrets, API keys, `.env` files, build output, or dependency folders.
- Test locally after meaningful changes, especially create round and round detail flows.
- Explain which files changed and why after edits.
